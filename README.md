# Oxidação e redução em química orgânica · simulador

Simulador interativo para revisão das principais reações de oxidação e redução de compostos orgânicos (Química Orgânica, PUCRS). Cada etapa mostra as setas de elétrons animadas, os átomos se movendo até a estrutura seguinte e um medidor com o número de oxidação do carbono que reage.

## Mecanismos

| # | Reação | Link direto |
|---|--------|-------------|
| 1 | Redução de cetona com NaBH₄ (acetona → 2-propanol) | `#nabh4` |
| 2 | Redução de éster com LiAlH₄ (acetato de etila → 2 etanol) | `#lialh4` |
| 3 | Oxidação de álcool 2º com ácido crômico (2-propanol → acetona) | `#jones` |
| 4 | Álcool 1º: PCC (aldeído) × reagente de Jones (ácido, via hidrato) | `#primario` |

Também inclui:
- medidor do número de oxidação do carbono, que se move a cada etapa;
- escada de níveis de oxidação, com oxidantes e redutores comuns;
- ferramenta "partindo de / quero obter", que indica o reagente para cada conversão;
- quadro comparativo e desafios com correção imediata.

Para abrir direto num mecanismo, acrescente o código ao endereço, por exemplo:
`https://SEU-USUARIO.github.io/oxidacao_reducao/#jones`


## Uso

- **Próxima / Anterior** ou as setas ← → do teclado avançam as etapas.
- **Repetir setas** anima de novo o movimento dos elétrons.
- **Reproduzir tudo** percorre o mecanismo inteiro automaticamente.

Arquivo HTML único, sem instalação. Funciona em computador e celular, com tema claro e escuro.
